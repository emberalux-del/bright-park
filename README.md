# Брайт Парк

В GitHub Pages открывается демонстрационный интерфейс из `index.html`. Рабочий кабинет использует отдельный Node.js сервер с SQLite. На нём путь `/` открывает кабинет жителя, а `/admin` открывает кабинет УК.

## Запуск

1. Установите Node.js 24. Скопируйте `.env.example` в `.env`. Укажите публичный HTTPS-адрес, имя и токен Telegram-бота, имя и длинный случайный пароль администратора. Токен и пароль остаются на сервере.
2. Запустите `node --env-file=.env cabinet/server.mjs`. Для локальной проверки веб-кабинета используйте `APP_ORIGIN=http://localhost:3000`.
3. Разместите сервер за HTTPS-прокси, включите ограничение частоты запросов к кабинету УК и храните файл SQLite на постоянном диске с резервным копированием. Не логируйте заголовки авторизации и тела заявок.
4. В BotFather настройте URL Mini App на адрес рабочего сервера. Для отдельного именованного Mini App заполните `TELEGRAM_APP_SHORT_NAME`. Для проверки связки с Telegram используйте тестового бота.

## Как привязать участок

1. Администратор открывает `/admin` в браузере и вставляет из Excel столбец номеров участков. Один номер на строку, без заголовка. Повторный импорт добавляет новые номера и сохраняет существующие.
2. Житель входит через Telegram и указывает номер участка и телефон для связи. Состояние заявки хранится на сервере и обновляется по кнопке «Проверить статус».
3. Администратор видит заявку и сверяет её с внутренним реестром УК. Для проверки используйте контакт, уже известный УК. Телефон из заявки введён жителем и сам по себе не подтверждает право на участок. По итогам проверки администратор подтверждает или отклоняет заявку. Подтверждённый доступ можно отозвать.
4. Для жителя, которого УК уже проверила, администратор выбирает участок и создаёт ссылку на 24 часа. Житель открывает её в Telegram и подтверждает привязку. Сервер использует ссылку один раз. Ссылку до использования можно отменить. Передавайте её лично проверенному жителю: привязку получает первый Telegram-аккаунт, который подтвердит приглашение.

Реестр в приложении содержит номера участков. Один Telegram-аккаунт может иметь одну активную привязку. Несколько членов семьи могут быть привязаны к одному участку после проверки или по отдельным приглашениям.

Пилот рассчитан на одного администратора УК. Перед загрузкой реальных телефонов согласуйте с УК порядок работы с персональными данными, доступ к базе и срок хранения заявок. Для нескольких администраторов понадобятся отдельные учётные записи и журнал с указанием сотрудника, принявшего решение.

## Вход по телефону из реестра

Установите Python 3 и зависимости командой `python3 -m pip install -r requirements.txt`. Если Python находится в виртуальном окружении, задайте путь к его исполняемому файлу в `PYTHON_BIN`.

1. В кабинете УК загрузите XLSX или CSV в UTF-8. В первой строке нужны колонки «Телефон» и «Участок». Для XLSX читается первый лист, максимум 2 000 строк и 2 МБ на файл. Номера участков с ведущими нулями храните в Excel как текст.
2. Импорт добавляет новые записи и сохраняет пароли существующих аккаунтов. Повтор одной пары допустим. Один телефон не может быть активен для двух участков. При смене участка или владельца отключите старую запись в кабинете УК. Это завершит сессии входа по телефону, аннулирует коды и очистит пароль. Повторная загрузка отключённого номера включает его заново. Отсутствие номера в новом файле не отключает его автоматически.
3. Для отправки кодов укажите на сервере `SMS_RU_API_ID`, при необходимости `SMS_RU_SENDER` и отдельный случайный `OTP_SECRET`. Например, секрет можно сгенерировать командой `openssl rand -hex 32`. На сервере требуется исходящий HTTPS до SMS.RU.
4. При первом входе житель запрашивает код на телефон из реестра и задаёт постоянный пароль. Код действует пять минут и используется один раз. Дальше житель входит по телефону и паролю. Код также используется для восстановления доступа. После смены или восстановления пароля старые сессии прекращают действовать.
5. Если встроенный браузер Telegram не сохраняет сессию, откройте HTTPS-адрес кабинета в обычном браузере. Доступ по отдельному приглашению Telegram работает по прежнему сценарию. При смене собственника УК отзывает также ранее выданные привязки и приглашения Telegram, если они использовались.

Ограничьте частоту запросов к маршрутам входа и SMS на HTTPS-прокси. Перед подключением жителей проверьте доставку кода на тестовый номер и вход в обычном браузере и целевых клиентах Telegram.
